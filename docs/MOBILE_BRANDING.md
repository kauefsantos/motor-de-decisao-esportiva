# Mobile branding

A identidade instalada do Bet Value usa ícones próprios em `public/icons/`:

- `favicon-32.png`
- `apple-touch-icon.png` (180x180)
- `icon-192.png`
- `icon-512.png`

No iOS, o ícone da Tela de Início pode ficar em cache. Depois de uma troca de ícone, remova o atalho antigo e adicione o site novamente pelo Safari para forçar a nova arte.

A sessão mobile usa o Google/Supabase normalmente e mantém um marcador local apenas para exigir nova autenticação após 30 dias. Esse marcador não substitui autenticação, allowlist ou validação das server functions.
